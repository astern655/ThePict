`$ARGUMENTS`

위 요청을 **직접 답하지 말고**, `panel` 워크플로에 넘겨라. 이 슬래시 커맨드는 멀티 에이전트 오케스트레이션에 대한 명시적 동의다.

```
Workflow({ scriptPath: ".claude/workflows/panel.js", args: "<위 요청 전문>" })
```

`name: "panel"`로는 해석되지 않는다 — 등록된 워크플로가 아니므로 반드시 `scriptPath`로 호출한다.

- `args`는 요청 문자열을 그대로 전달한다. 요약하거나 다시 쓰지 마라 — 관점별 제안자가 원문을 봐야 한다.
- 요청이 비어 있으면 워크플로를 실행하지 말고 무엇을 검증할지 되물어라.
- 워크플로는 백그라운드에서 돌고 완료 알림이 온다. 결과를 받으면 `answer` 필드를 사용자에게 그대로 제시하고, 그 아래에 한 줄로 심사 요약을 덧붙여라:
  `> 패널: <ranking> · 주장 <claimsSurvived>개 통과 / <claimsRefuted>개 반박 탈락`
- 에이전트를 10개 이상 띄우므로 토큰 소모가 크다. 사용자가 이 커맨드를 명시적으로 호출했을 때만 실행한다.
